# 🏦 fin-account-hub
> **[FIN-M] 디지털 계좌 통합 관리 플랫폼**  
> 사조참치 팀 (4인)

---

## 📌 프로젝트 소개

여러 계좌의 잔액 조회 및 이체를 단일 창구에서 통합 관리하는 **MSA 기반 디지털 금융 플랫폼**입니다.  
OpenFeign을 통한 동기 잔액 검증과 **Confluent Schema Registry (Avro)** 기반의 Kafka 비동기 이체 알림을 결합하여 데이터 정합성과 신뢰성 있는 알림 체계를 구현했습니다.
